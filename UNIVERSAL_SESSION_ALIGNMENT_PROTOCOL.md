# Universal Session Alignment Protocol

Purpose: a new session reads the project, then states what it understands before doing any work.
Applies to any project and any AI participant. Product names used here are examples, not requirements.

## 1. Bootstrap

Read `AGENTS.md` first. Its own instruction — Read AGENTS.md first, then follow its Mandatory Session Bootstrap — defines the alignment modes and the reading order; this protocol does not repeat them.

## 2. What to report

- The repository and `main` commit you verified, and your evidence mode: full local access, remote only, or partial.
- Documents you read, and documents you skipped.
- Current position, next step, and what is not authorised.
- Anything `UNVERIFIED` or contradictory, with the exact path and section.

Label each statement `[FACT]` (cited), `[DECISION]` (approved and cited), `[INFERENCE]`, or `[UNVERIFIED]`.

## 3. Boundaries

Alignment is read-only. Reading is not permission to edit, commit, push or merge. Never invent a path, section or requirement.
